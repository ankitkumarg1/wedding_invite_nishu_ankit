Wedding invitation website with background music

1. Put your legally obtained Ramayana soundtrack MP3 in this same folder.
2. Rename the audio file to: ramayana-song.mp3
3. Keep index.html and ramayana-song.mp3 together.
4. Upload the folder contents (or a ZIP containing both files) to Netlify.
5. Guests tap OPEN THE GATES to start the music. The MUSIC ON/OFF button controls playback.

The MP3 audio file is not included in this package. You must provide the audio file and ensure you have permission to use it.
